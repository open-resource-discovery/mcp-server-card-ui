# Security Overrides

Overrides in `package.json` that force safe versions of transitive dependencies.
Each entry should be removed once `npm audit` reports no advisories for that package
without the override in place.

---

## Root (`package.json`)

### minimatch

- **Override**: `"minimatch": "11.0.1"`
- **CVE**: CVE-2026-118764
- **GHSA**: GHSA-g3hv-75wg-m249
- **Severity**: medium
- **Summary**: minimatch has potential denial of service via globparts amplification
- **Vulnerable range**: `>= 7.0.0, < 11.0.1`
- **Added**: 2026-11-17
- **Remove when**: `npm audit` reports no advisories for `minimatch`
